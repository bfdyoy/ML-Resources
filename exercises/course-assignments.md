# Course Assignments & Book Exercises

[← Exercises](README.md)

Free, high-quality problem sets from universities and textbooks. These are the hardest and most rewarding practice available.

## Structured exercise curricula
| Resource | What you do | Level | Fits after |
|---|---|---|---|
| [ARENA 3.0](https://github.com/callummcdougall/ARENA_3.0) | A complete exercise-based curriculum: PyTorch fundamentals, transformers from scratch, mechanistic interpretability, RL (DQN/PPO/RLHF), and LLM evals. Every exercise comes with tests and solutions. | L2→L3 | Path 2 |
| [Karpathy: Neural Networks: Zero to Hero](https://github.com/karpathy/nn-zero-to-hero) | Exercises in each lecture's description, plus reimplementing each lecture from memory | L2 | DL-01…DL-06 |
| [UDL notebooks](https://github.com/udlbook/udlbook) | ~70 notebooks with fill-in-the-blank code for every chapter of *Understanding Deep Learning* | L2 | Path 2 |
| [UvA DL tutorials](https://uvadlc-notebooks.readthedocs.io/) | Notebook tutorials to extend (GNNs, transformers, flows, energy-based models, SimCLR) | L2→L3 | Path 2 |

## Book exercise sets
| Book | Exercises | Tips |
|---|---|---|
| [ISLP](https://www.statlearning.com/) | Conceptual + applied exercises at the end of every chapter, plus labs | Do the *applied* ones in Python. Community solutions exist, but try first. |
| [Géron's notebooks](https://github.com/ageron/handson-mlp) | End-of-chapter exercises, with solutions in the notebooks | The best "applied" exercise set for classical ML + DL |
| [D2L](https://d2l.ai/) | Exercises after every section | The "modify this code" exercises are especially good |
| [UDL](https://udlbook.github.io/udlbook/) | End-of-chapter problems, with answers to selected ones on the site | Pen-and-paper math. Great for DL theory. |
| [MML](https://mml-book.github.io/) | End-of-chapter exercises | Do them for the chapters you use in the math lessons |
| [Sutton & Barto](http://incompleteideas.net/book/the-book-2nd.html) | Exercises throughout the text | Chapters 2–6 especially |
| [Raschka, LLMs from Scratch](https://github.com/rasbt/LLMs-from-scratch) | Chapter exercises, with solutions in the repo | GEN-01, GEN-02 |
| [fastbook](https://github.com/fastai/fastbook) | Questionnaire + "further research" at the end of each chapter | DL-02, DL-04 |
