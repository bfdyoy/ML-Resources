# Exercises & Practice

Reading gives you understanding, and practice turns it into skill. This folder collects **every kind of practice** you need to become
proficient, ordered from small drills to full projects.

| File | What's inside | Use it for |
|---|---|---|
| [Drills & puzzles](drills-and-puzzles.md) | NumPy/pandas drills, tensor/autodiff/GPU puzzles, ML coding problems | Daily 20–30 min reps, and fluency |
| [From-scratch ladder](from-scratch-ladder.md) | 45 implement-it-yourself exercises, from linear regression to RAG, each with a correctness check | Deep understanding. This is the core of the practice. |
| [Course assignments & book exercises](course-assignments.md) | Free university assignments (CS231n, CS224n, CS336, …), book exercise sets, structured curricula (ARENA) | Hard, graded practice with known-good solutions |
| [Projects & competitions](projects-and-competitions.md) | Project ideas by level, Kaggle strategy, portfolio guidance | Applying everything end to end |
| [Interview & system-design prep](interview-prep.md) | Question banks, solved problem books, system-design case studies | Consolidation, and job readiness |

## A weekly practice routine (7–8 h/week learner)

| When | What | Time |
|---|---|---|
| 3× per week | One drill from [drills & puzzles](drills-and-puzzles.md) (e.g. 5 Deep-ML problems, or one Tensor-Puzzles section) | 20–30 min each |
| 1× per week | One rung of the [from-scratch ladder](from-scratch-ladder.md) that matches your current lesson | 1.5–2 h |
| Every lesson | The lesson's mini-project (in the lesson file) | 1–3 h |
| End of each path | The path capstone (in the path file) | 8–15 h |
| Monthly | 10 questions from [interview prep](interview-prep.md), answered out loud or in writing, without notes | 1 h |

## Principles
1. **Don't copy code.** Type it yourself. Better still, write it from memory after reading.
2. **Always test against a reference.** Every from-scratch exercise has a check (e.g. "matches `sklearn` to 1e-6"). Passing that check is what counts as done.
3. **Struggle first, then look.** Give yourself 20–30 minutes before opening a solution.
4. **Log what you learn.** One line per exercise in [PROGRESS.md](../PROGRESS.md): what broke, and what fixed it.
