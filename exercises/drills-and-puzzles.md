# Drills & Puzzles

[← Exercises](README.md)

Short, repeatable exercises that build fluency. They're good for a 20–30 minute session.

## Data manipulation fluency
| Resource | What it drills | Level | When |
|---|---|---|---|
| [numpy-100](https://github.com/rougier/numpy-100) | 100 NumPy exercises, from trivial to tricky (vectorization, broadcasting, fancy indexing) | L1→L2 | Before and during CORE-01 |
| [pandas_exercises](https://github.com/guipsamora/pandas_exercises) | Filtering, grouping, merging, time series, visualization | L1 | CORE-01 |
| [Python Data Science Handbook](https://github.com/jakevdp/PythonDataScienceHandbook) | Worked notebooks for NumPy, pandas, and Matplotlib (read + run) | L1 | CORE-01 |

## Tensor & autodiff puzzles (Sasha Rush)
These are some of the best exercises available for building real understanding. Each one is a set of small, satisfying puzzles with tests.

| Resource | What it drills | Level | When |
|---|---|---|---|
| [Tensor-Puzzles](https://github.com/srush/Tensor-Puzzles) | Re-implement NumPy/PyTorch functions using only broadcasting and indexing, in one line each | L2 | DL-02 |
| [Autodiff-Puzzles](https://github.com/srush/Autodiff-Puzzles) | Derive and implement derivatives for tensor functions | L2 | DL-01 |
| [GPU-Puzzles](https://github.com/srush/GPU-Puzzles) | Learn CUDA-style GPU programming (map, zip, pooling, matmul) in Python via Numba | L2→L3 | Toolbox 11 |
| [LLM-Training-Puzzles](https://github.com/srush/LLM-Training-Puzzles) | Memory and compute puzzles about distributed training (data/tensor/pipeline parallelism) | L3 | Toolbox 11 |
| [Thinking Like Transformers (raspy)](https://github.com/srush/raspy) | Write programs in RASP, a language that compiles to transformer attention | L3 | DL-06 |
| [Transformer Circuits Exercises](https://transformer-circuits.pub/2021/exercises/index.html) | Pen-and-paper exercises on attention circuits | L3 | DL-06 + toolbox 12 |
